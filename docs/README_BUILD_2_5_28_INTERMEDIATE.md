# WEEE Platform 2.5.31 intermediate

## Παραγωγή
- Νέο full-width dashboard Παραγωγής με δύο υποκαρτέλες: «Παραγωγή ανά ΑΗΗΕ» και «Παραγωγή ανά Τμήμα / Άτομο».
- Επιλογή Ημέρα / Μήνας / Τρίμηνο / Έτος, default τρέχων μήνας.
- Κατηγορίες ΑΗΗΕ 1–6 με αναπτυσσόμενες/συμπτυσσόμενες στήλες υποκατηγοριών.
- Προβολή Σύνολο / HERMES / Λοιποί και κοινό production data model για Android/Windows καταχωρίσεις.
- Τμήμα/Άτομο υποστηρίζει είτε συγκεντρωτική ποσότητα τμήματος είτε ποσότητες ανά εργαζόμενο, μαζί με το ΑΗΗΕ/υλικό εργασίας.

## Μητρώα
- Προστέθηκε «Τμήμα Εξωτερικών».
- Στα Τμήματα προστέθηκε πεδίο «Θέση».
- Προστέθηκε μητρώο «Εργαζόμενοι» με Ονοματεπώνυμο, Τηλέφωνο και προαιρετική σύνδεση με Τμήμα.
- Οι εργαζόμενοι υποστηρίζουν μη ενεργό / επανενεργοποίηση όπως τα υπόλοιπα μητρώα.

## Backend
- Νέο production_work_entries schema/API, με πηγή WINDOWS/ANDROID, τμήμα, προαιρετικό εργαζόμενο, κατηγορία ΑΗΗΕ, kg και supplier group.
- Forward-compatible migration για το νέο πεδίο Θέση στα υπάρχοντα persistent DBs.
