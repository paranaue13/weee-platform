- Μητρώα: διατήρηση ενεργού tab και scroll μετά από edit / ενεργοποίηση / απενεργοποίηση.
- Sticky γραμμή tabs στα Μητρώα.
- Παραλαβή: αναδιάταξη φόρμας σε ευανάγνωστες ενότητες.
- ΔΠΠ αντί DPP στην οθόνη, με επόμενο αύξοντα αριθμό για νέα παραλαβή.
- Ημερομηνία Αναφοράς προεπιλέγεται στην τρέχουσα ημερομηνία και διατηρείται στο δελτίο.
- Κάδος εισόδου / κάδος εξόδου με άμεση οδηγία ζυγαριάς: ↑ Ανέβασε / ↓ Κατέβασε / Ίδιο απόβαρο.
- Ξένα υλικά / Μη ΑΗΗΕ / ειδική διαχείριση εμφανίζονται read-only στην Παραλαβή, ως δεδομένα που ανήκουν στη ροή Ταξινόμησης.
- Ελαφρώς πιο ζωντανός, επαγγελματικός χρωματισμός στο αριστερό κύριο μενού. Το δεξί τμήμα δεν άλλαξε.
- Διατηρούνται οι αλλαγές 2.5.1 στην Αποθήκη ΑΗΗΕ και sticky headers μεγάλων πινάκων.

Σημείωση: η πλήρης αυτόματη παραγωγή των πεδίων Ξένων Υλικών / Ειδικής Διαχείρισης από δομημένα δεδομένα Ταξινόμησης θα ολοκληρωθεί όταν τα αντίστοιχα πεδία αποθηκεύονται δομημένα στη φόρμα Ταξινόμησης. Στο παρόν build δεν επιτρέπεται διπλή χειροκίνητη καταχώρηση από την Παραλαβή.
