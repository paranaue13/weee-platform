# WEEE Platform 2.5.21 Intermediate

- First view after application start defaults to the current local day in daily operational screens.
- Monthly screens (including Αποθήκη ΑΗΗΕ) default to the current local month.
- The current day has a distinct Windows/mobile-calendar style outline even when another day is selected.
- Receipt summary cards use separate lines: point count, then kilograms.
- Existing click/open behavior for receipts, sorting sheets, and registries is retained.
- Persistent Windows database behavior introduced in 2.5.20 is retained.
