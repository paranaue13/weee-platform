# WEEE Platform 2.5.23 Intermediate

- Performance: removed automatic 4-second full reloads from Receipts / Sorting / WEEE warehouse.
- WEEE warehouse: current-inventory layout, continuous scroll, compact KPIs, single date picker, blank zero cells, alternating rows, full-width 10-column stock view.
- Receipt small points: truck first/last weighing synchronization, summary fields, cleaner multi-order blocks, no historical-import UI notes.
- Settings: appearance, language, profile and role controls grouped in one bottom Settings menu; dark mode retained.
- Sorting: daily Excel export named DD.MM.YYYY.xlsx; one worksheet per sorting and final `Σύνολο Μέρας`, based on the imported workbook template and legacy-category formulas.
- Reports/exports: user observations only; no automatic workflow-status commentary.
