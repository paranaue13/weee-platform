# WEEE Platform Build 2.5.15 Intermediate

## Αλλαγές
- Διόρθωση Μητρώων: ανεξάρτητη φόρτωση κάθε λίστας ώστε αστοχία σε ένα επιμέρους registry να μη μπλοκάρει τα υπόλοιπα.
- Διατήρηση ξεχωριστών λιστών/ρόλων για Προμηθευτές, Μεταφορείς και Συνεργάτες.
- Παραλαβές: νέα διάταξη Ημέρες / Μήνες με αναζήτηση.
- Προβολή μόνο της επιλεγμένης ημέρας.
- Δεξί ημερολόγιο επιλογής ημέρας με pastel χρωματισμό από την κατάσταση ταξινόμησης.
- Συμπαγής επισκόπηση ανά τύπο φορτίου: Container, Καρότσα, Μικρά σημεία, μαζί με Σύνολο ημέρας.
- Νέα λεπτομερής λίστα ημέρας και τρία κύρια controls: Νέα Παραλαβή, Εξαγωγή, περισσότερα.
- Διατηρείται η υπάρχουσα light εμφάνιση του build χωρίς αλλαγή της συνολικής οπτικής γλώσσας.
- Το πακέτο δεν περιέχει `.venv`, ώστε να παραμένει μικρό και φορητό.
