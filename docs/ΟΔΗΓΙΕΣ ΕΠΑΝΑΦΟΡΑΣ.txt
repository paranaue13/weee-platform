ΟΔΗΓΙΕΣ ΕΠΑΝΑΦΟΡΑΣ ΤΗΣ ΕΦΑΡΜΟΓΗΣ WEEE PLATFORM
(για καινούργιο υπολογιστή ή καινούργιο δίσκο - γραμμένες για μη προγραμματιστή)
================================================================================

ΠΡΙΝ ΞΕΚΙΝΗΣΕΙΣ - ΤΙ ΕΙΝΑΙ ΤΙ
--------------------------------------------------------------------------------
Η εφαρμογή έχει ΤΡΙΑ κομμάτια. Και τα τρία έχουν αντίγραφα εκτός του δίσκου του υπολογιστή:

  1) Η ΒΑΣΗ ΔΕΔΟΜΕΝΩΝ (όλες οι παραλαβές, υλικά, φορτώσεις κ.λπ.)
     - Στο USB «WEEE-BACKUP»:   WEEE-Backups\db\weee_db_ΗΜΕΡΟΜΗΝΙΑ_ΩΡΑ.zip      (δεν είναι κρυπτογραφημένο)
     - Στο OneDrive:            OneDrive\WEEE-Backups\db\weee_db_ΗΜΕΡΟΜΗΝΙΑ_ΩΡΑ.zip.wbk   (ΚΡΥΠΤΟΓΡΑΦΗΜΕΝΟ· θέλει τον κωδικό σου)

  2) ο ΚΩΔΙΚΑΣ της εφαρμογής
     - Στο GitHub (ιδιωτικό):   https://github.com/paranaue13/weee-platform
     - Στο USB και στο OneDrive: WEEE-Backups\code\weee_code_ΗΜΕΡΟΜΗΝΙΑ_ΩΡΑ.bundle  (πλήρες πακέτο με όλο το ιστορικό)

  3) ΑΛΛΑ ΑΡΧΕΙΑ
     - Φωτογραφίες/αναφορές/πρότυπα:   WEEE-Backups\docs\  (στο OneDrive είναι κρυπτογραφημένα .wbk)
     - Αρχεία .env με στοιχεία σύνδεσης (Electrocycle): ΜΟΝΟ στο USB, φάκελος env\, κρυπτογραφημένο (.wbk)
     - Αρχικά Excel (φάκελος «Files»):  ΜΟΝΟ στο USB, φάκελος excel\ (1 φορά την εβδομάδα)

  ΤΟ ΜΕΓΑΛΟ ΜΥΣΤΙΚΟ: ο ΚΩΔΙΚΟΣ ΚΡΥΠΤΟΓΡΑΦΗΣΗΣ που έβαλες με το «ΡΥΘΜΙΣΗ ΚΩΔΙΚΟΥ BACKUP.cmd».
  Δεν είναι γραμμένος πουθενά στον υπολογιστή. Χωρίς αυτόν ΔΕΝ ανοίγουν τα αρχεία .wbk (OneDrive και .env).
  Το USB όμως έχει τη βάση σε απλό zip, οπότε ΠΑΝΤΑ μπορείς να σώσεις τη βάση από το USB ακόμα κι αν ξεχάσεις τον κωδικό.
  Μαζί με τα αντίγραφα υπάρχει φάκελος «keys» με το αρχείο backup_private_key.enc (κλειδωμένο με τον κωδικό σου) - χρειάζεται κι αυτό.

--------------------------------------------------------------------------------
ΠΕΡΙΠΤΩΣΗ Α: Ο υπολογιστής δουλεύει αλλά χάλασε η βάση (π.χ. διαγράφηκαν δεδομένα)
--------------------------------------------------------------------------------
Το πιο εύκολο: υπάρχουν αντίγραφα κάθε 15 λεπτά στον φάκελο
   C:\Users\paran\AppData\Local\WEEE Platform\data\backups
Βήματα:
  1. Κλείσε την εφαρμογή και τον server (το παράθυρο που τρέχει το START_WEEE_PLATFORM.cmd).
  2. Στον φάκελο C:\Users\paran\AppData\Local\WEEE Platform\data\ κράτα ένα αντίγραφο του weee_dev.db σε άλλον φάκελο (για ασφάλεια).
  3. Σβήσε από τον ίδιο φάκελο τα αρχεία weee_dev.db-wal και weee_dev.db-shm (αν υπάρχουν).
  4. Αντίγραψε το αντίγραφο που θέλεις (π.χ. από το backups) πάνω στο weee_dev.db.
  5. Ξεκίνα ξανά την εφαρμογή.

--------------------------------------------------------------------------------
ΠΕΡΙΠΤΩΣΗ Β: ΚΑΙΝΟΥΡΓΙΟΣ ΥΠΟΛΟΓΙΣΤΗΣ ή ΚΑΙΝΟΥΡΓΙΟΣ ΔΙΣΚΟΣ (χάλασε ο παλιός)
--------------------------------------------------------------------------------
ΒΗΜΑ 1 - Εγκατάσταση προγραμμάτων (μία φορά)
  α. Python 3.13 (python.org -> Downloads). Στην εγκατάσταση τσέκαρε «Add python.exe to PATH».
  β. Git for Windows (git-scm.com).
  γ. (προαιρετικό) 7-Zip.

ΒΗΜΑ 2 - Ο κώδικας
  Επιλογή 1 (αν υπάρχει ίντερνετ): άνοιξε το PowerShell και γράψε:
      cd Desktop
      git clone https://github.com/paranaue13/weee-platform.git "HER app"
  (θα ζητήσει σύνδεση στο GitHub με τον λογαριασμό σου). Ο φάκελος που φτιάχνεται είναι ο φάκελος της εφαρμογής.
  Επιλογή 2 (χωρίς ίντερνετ, από το USB ή το OneDrive): αντίγραψε το πιο πρόσφατο αρχείο από WEEE-Backups\code\*.bundle
  στην Επιφάνεια Εργασίας και στο PowerShell γράψε:
      git clone weee_code_ΗΜΕΡΟΜΗΝΙΑ_ΩΡΑ.bundle "HER app"

ΒΗΜΑ 3 - Το περιβάλλον Python
  Στο PowerShell, μέσα στον φάκελο της εφαρμογής:
      cd backend
      python -m venv .venv
      .venv\Scripts\python.exe -m pip install -r requirements.txt

ΒΗΜΑ 4 - Η βάση
  1. Φτιάξε τον φάκελο  C:\Users\ΟΝΟΜΑ_ΧΡΗΣΤΗ\AppData\Local\WEEE Platform\data
     (γράψε το %LOCALAPPDATA% στη γραμμή διεύθυνσης του Εξερευνητή και μετά φτιάξε φακέλους WEEE Platform και data).
  2. ΑΠΟ ΤΟ USB: πάρε το πιο πρόσφατο  WEEE-Backups\db\weee_db_....zip, κάνε δεξί κλικ -> «Εξαγωγή όλων» και πάρε το αρχείο weee_dev.db.
     ΑΠΟ ΤΟ ONEDRIVE: το αρχείο είναι .wbk (κρυπτογραφημένο). Χρησιμοποίησε το εργαλείο επαναφοράς (παρακάτω).
  3. Βάλε το weee_dev.db μέσα στον φάκελο data.

  Εργαλείο επαναφοράς (ελέγχει και την ακεραιότητα και δείχνει πόσες εγγραφές έχει η βάση):
      cd backend\scripts
      ..\.venv\Scripts\python.exe restore_backup.py "ΔΙΑΔΡΟΜΗ\weee_db_ΗΜΕΡΟΜΗΝΙΑ.zip.wbk" "C:\ΦΑΚΕΛΟΣ_ΕΠΑΝΑΦΟΡΑΣ" --key "ΔΙΑΔΡΟΜΗ\keys\backup_private_key.enc"
  Θα ζητήσει τον ΚΩΔΙΚΟ (δεν φαίνεται όταν τον γράφεις). Στο τέλος γράφει «Έλεγχος ακεραιότητας βάσης: ok» και τα πλήθη (υλικά, φορτώσεις...).
  Για να το τρέξεις πριν στήσεις τα Βήματα 2-3 χρειάζεσαι: python -m pip install cryptography και τα αρχεία tools\restore_backup.py και tools\backup_crypto.py
  από τον φάκελο WEEE-Backups\tools (είναι δίπλα στα αντίγραφα).

ΒΗΜΑ 5 - Τα άλλα αρχεία
  - .env: αποκρυπτογράφησέ το με το ίδιο εργαλείο (αρχείο WEEE-Backups\env\env_....wbk) και βάλε το αποτέλεσμα στον φάκελο backend με όνομα .env
  - Φωτογραφίες/αναφορές: άνοιξε το WEEE-Backups\docs\docs_....zip και αντίγραψε τον φάκελο «WEEE Platform» στα Έγγραφα (Documents) και τον φάκελο «report_templates»
    στο  %LOCALAPPDATA%\WEEE Platform\data\report_templates
  - Αρχικά Excel: από το USB, φάκελος excel\Files_....zip -> αποσυμπίεσε στην Επιφάνεια Εργασίας (φάκελος «HER app\Files»).

ΒΗΜΑ 6 - Εκκίνηση
  Διπλό κλικ στο START_WEEE_PLATFORM.cmd (μέσα στον φάκελο της εφαρμογής). Άνοιξε τον browser στη διεύθυνση http://127.0.0.1:8000
  Έλεγξε ότι φαίνονται τα δεδομένα σου.

ΒΗΜΑ 7 - Ξαναστήσιμο των αυτόματων αντιγράφων
  Κάνε δεξί κλικ στο PowerShell -> «Εκτέλεση ως διαχειριστής» (δεν χρειάζεται συνήθως) και γράψε:
      powershell -ExecutionPolicy Bypass -File backend\scripts\install_backup_task.ps1
  Μετά διπλό κλικ στο «ΡΥΘΜΙΣΗ ΚΩΔΙΚΟΥ BACKUP.cmd» για νέο κωδικό (ή βάλε πίσω τα παλιά αρχεία κλειδιών από τον φάκελο keys).
  Μετά διπλό κλικ στο «ΑΝΕΒΑΣΜΑ ΣΤΟ GITHUB.cmd» για να ξανασυνδεθεί το GitHub.

ΒΗΜΑ 8 - Το Android
  Η διεύθυνση του νέου υπολογιστή αλλάζει (είναι η διεύθυνση δικτύου του υπολογιστή). Ανοίγοντας το START_LAN_SERVER_FOR_ANDROID.cmd δείχνει τη νέα διεύθυνση.
  Στο κινητό πρέπει να δείχνει στη νέα διεύθυνση (το τηλέφωνο και ο υπολογιστής στο ίδιο Wi-Fi, ή Tailscale).

--------------------------------------------------------------------------------
ΤΙ ΝΑ ΚΑΝΩ ΑΝ ΚΑΤΙ ΔΕΝ ΔΟΥΛΕΥΕΙ
--------------------------------------------------------------------------------
  - Διάβασε το αρχείο «ΑΝΤΙΓΡΑΦΑ ΑΣΦΑΛΕΙΑΣ - ΚΑΤΑΣΤΑΣΗ.txt» (Επιφάνεια Εργασίας): γράφει ξεκάθαρα τι πρόβλημα υπάρχει.
  - Η εφαρμογή δείχνει κόκκινη ειδοποίηση στην πάνω μπάρα αν δεν έχει γίνει εξωτερικό αντίγραφο για πάνω από 36 ώρες.
  - Αν χάσεις τον κωδικό κρυπτογράφησης: η βάση στο USB (απλό zip) δεν επηρεάζεται. Στο OneDrive/.env δεν υπάρχει τρόπος να ανοίξουν.
    Φτιάξε νέο κωδικό με το «ΡΥΘΜΙΣΗ ΚΩΔΙΚΟΥ BACKUP.cmd»: τα ΝΕΑ αντίγραφα θα ανοίγουν με τον νέο.
