# WEEE Platform 1.8
Unified Windows + Backend + Android build.

Important: copy your existing `backend/weee_dev.db` into this build before first normal use if you want to keep existing data. Startup migrations/seeding add the supplied registries without deleting receipts/sorting data.

Android-specific UI changed in 1.8, so build/install a new APK from the included `android` project.
