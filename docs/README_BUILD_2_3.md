# WEEE Platform Build 2.3

- Search/typeahead fields in receipt creation instead of plain dropdowns for carrier, supplier and containers. Receipt type uses buttons.
- Suppliers/Carriers/Partners support active/inactive status; inactive entries remain visible in Master Data/history but are excluded from operational choices.
- Carrier-specific driver registry.
- Visitor Book with manual Logistics entries. Receipt drivers are logged automatically: first weighing creates arrival time; completed second weighing creates departure time.
- Keeps Build 2.2.1 calendar history and Build 2.2 WEEE warehouse drill-down.
