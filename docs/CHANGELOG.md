# WEEE Platform – Συγκεντρωτικό Changelog

Τα προηγούμενα README/CHANGELOG builds έχουν συγκεντρωθεί σε αυτόν τον φάκελο ώστε το root να παραμένει καθαρό.

## 2.5.13
- Dashboard: μόνο Ανοιχτά Φορτία, Ταξινόμηση σε εξέλιξη, Προγραμματισμένες Φορτώσεις. Κατάσταση ημερών μόνο όταν υπάρχουν ανοιχτές ταξινομήσεις.
- Παραλαβές/Ταξινόμηση: μικρό κενό ανά εργάσιμη εβδομάδα και status dots.
- Popups: resize, maximize/restore, minimize/close στα βασικά operational popups.
- Μεταφορείς/Οδηγοί: τηλέφωνο οδηγού.
- Μικρά Σημεία: ανά εντολή ζυγολογίου, δελτίο αποστολής, σφραγίδα, 1η/2η ζύγιση, ΔΠΠ. Η επόμενη 1η ζύγιση προτείνεται από την προηγούμενη 2η και παραμένει editable.
- Ταξινόμηση: ξένα/ειδικά μόνο ως kg, Αμιγές, αυτόματο ΝΑΙ/ΟΧΙ στο export, edit/delete παραλαβής.
- Διαγραφή παραλαβής: soft-delete, αποκλεισμός από κανονικά σύνολα και αρχείο με επαναφορά.
- Excel/PDF export: εικονίδια και mapping στοιχείων ανά load.
- Αποθήκη ΑΗΗΕ: parent code, ιστορικός μήνας, opening/current stock από κινήσεις και tabs μηνών.
