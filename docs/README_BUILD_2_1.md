# WEEE Platform 2.1

Windows workflow preview update:
- Παραλαβές και Ταξινόμηση: tabs Μήνα → Ημέρας, με προεπιλογή τρέχουσας ημερομηνίας όταν υπάρχει.
- Κοινές στήλες: Ημερομηνία, Αριθμός Εντολής, Μεταφορέας, Προμηθευτής, Καθαρό Βάρος, Κατάσταση.
- Μικρά Σημεία ομαδοποιημένα/collapsible ανά φορτηγό.
- Clickable ελληνική Κατάσταση ανοίγει Δελτίο Συνολικής Αναφοράς.
- Δελτίο: καθαρό παραλαβής, σύνολο ταξινόμησης, διαφορά και συγκεντρωτικός πίνακας επίσημων κωδικών.
- Αποθήκη ΑΗΗΕ: δύο live ενότητες, προς επεξεργασία και προς αποστολή. Η Ταξινόμηση δείχνει τον τρέχοντα μήνα. Αρχικό απόθεμα/επεξεργασία/αποστολές παραμένουν κενά έως την υλοποίηση των αντίστοιχων workflows.
- Επιλογές container εμφανίζουν αριθμό, μεταφορική και απόβαρο.
